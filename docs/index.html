Peptide characterization

How it works

Enter a one-letter amino acid sequence (standard 20 L-amino acids). The app validates the sequence, summarizes composition, builds a linear peptide in RDKit via amide coupling, and reports SMILES, a 2D structure, and molecular descriptors.

Supported: linear chains only. Not supported: D-amino acids, unnatural residues, cyclization, or post-translational modifications.

Connect API backend

Why connect? GitHub Pages hosts this page as HTML, CSS, and JavaScript only. Structure building and RDKit run on a separate FastAPI server (for example on Render). Paste your deployed API URL once; it is saved in this browser.

First request slow? Free hosting may wake up after idle time—wait about 30 seconds and try again.

Deploy from this repo's Dockerfile / render.yaml, then copy the service URL from the Render dashboard. See the README deploy section for ALLOWED_ORIGINS and the PEPTIDE_API_URL GitHub Actions variable (hides this panel when set).

Sequence & build options

Choose a benchmark example or type your own sequence. Results update automatically after you stop typing (when the API is connected).

Curated test sequences from the project benchmark (data/benchmark_sequences.csv)—validation edge cases, Gly/Pro coupling, and charged motifs. Select — custom — for your own sequence.

Standard single-letter code (A, R, N, D, …). Spaces are ignored; letters are uppercased. Unsupported characters (e.g. B, X, Z) are rejected before building.

Asp/Glu side-chain protection (why this checkbox matters)

During assembly, aspartic acid and glutamic acid side chains are temporarily modeled as methyl esters so coupling happens on the backbone, not the side chain.

When this box is checked (default), those esters are removed after assembly and the side chains are free carboxylic acids—the usual representation for peptides in aqueous models.

Uncheck only if you want to inspect or export the protected (methyl ester) form.

Sequence generator

Create new one-letter sequences for exploration. Click Generate and use sequence to fill the main input and run a full characterization. Chemistry rules are unchanged—only the sequence string changes.

Builds a sequence of the given length using the standard 20 amino acids (uniform random).

Combinatorial mode can return many sequences; the JSON block below summarizes build success for a preview subset (not full descriptors for every variant). 


      


      

        

          
Composition

          

            Summary of the input sequence (amino-acid letters), not the
            3D conformer. Counts use fixed property classes per residue (hydrophobic,
            charged, polar, aromatic).
          

          

            What do these fields mean?
            

              
length

              
Number of residues after normalization.

              
hydrophobic

              
Count of residues classified hydrophobic (e.g. A, V, L, I).

              
charged

              
Residues with charged side chains in the neutral-pH model.

              
positive / negative

              
Subset of charged (e.g. K, R vs D, E).

              
polar

              
Uncharged polar side chains.

              
aromatic

              
F, W, Y.

              
counts

              
Per-letter occurrence dictionary.

Structure

          

            SMILES is the canonical linear structure after peptide
            assembly. The 2D image is an RDKit depiction of that molecule
            (same graph used for descriptors).
          

          

            Copy SMILES into other tools (Marvin, docking pipelines, etc.). This is the
            assembled molecule, not a predicted bioactive conformation. 2D layout only—batch
            3D export is available via the repo CLI.

Whole-molecule descriptors

        

          Properties computed from the built SMILES with RDKit. Useful for quick
          ADME-style screening; not a substitute for experimental measurement.
        

        

          Descriptor glossary
          

            
molecular_weight

            
Average molecular weight (Da).

            
exact_molecular_weight

            
Monoisotopic mass.

            
logp

            
Crippen logP (lipophilicity estimate).

            
tpsa

            
Topological polar surface area (Å²).

            
hbond_donors / hbond_acceptors

            
Lipinski H-bond donor and acceptor counts.

            
rotatable_bonds

            
Rotatable bonds (rough flexibility proxy).

            
ring_count

            
Number of rings in the molecular graph.

            
heavy_atom_count

            
Non-hydrogen atoms.

            
fraction_csp3

            
Fraction of sp³ carbons.

            
formal_charge

            
Net formal charge in the RDKit model.

            
num_atoms / num_bonds

            
Atoms and bonds in the graph.

        Method & limitations (chemistry model)
        
    
          
  • Standard 20 L-amino acids only (validated alphabet).
    • 
          
  • 
            Linear peptides: iterative C-terminal carboxyl to incoming α-amine coupling
            (RDKit reaction SMARTS; Gly and Pro handled as distinct cases).
          
    • 
          
  • 
            Asp/Glu: side-chain methyl esters during assembly; hydrolyzed to acids by
            default (see checkbox above).
          
    • 
          
  • 
            Advanced batch export (CSV, 3D SDF, grids):
            README — export peptide visuals.
